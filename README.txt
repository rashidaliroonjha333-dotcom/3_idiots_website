# 3 Idiots — 8-page fashion store website

A responsive multi-page front-end website for a shop selling shoes, clothes, and slippers.

## Pages
1. `index.html` — Home
2. `shoes.html` — Shoes collection
3. `clothes.html` — Clothes collection
4. `slippers.html` — Slippers collection
5. `new-arrivals.html` — New arrivals
6. `about.html` — Our story
7. `contact.html` — Contact form
8. `cart.html` — Shopping bag

## Run in VS Code
1. Extract `3_idiots_website.zip`.
2. Open the extracted `3_idiots_website` folder in VS Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Use the navigation bar to move between all eight pages.

## Features
- Responsive layout for desktop and mobile
- Shared styling and navigation across all pages
- Product cards and sorting by price
- Add-to-bag functionality saved in browser local storage
- Cart quantity controls, remove buttons, subtotal and delivery calculation
- Contact and newsletter demo forms

## Notes
- Product images are loaded from Unsplash, so internet access is needed to display them.
- The contact form, newsletter form, and checkout are front-end demos. Connect them to an email service, backend, and payment provider before using this as a real store.
- Replace the example email `hello@3idiots.example` with your real store email.
- Product names, prices, and images can be edited in `script.js`.
